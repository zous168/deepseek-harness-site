Product

一套运行时，多种入口

一切皆插件。你在桌面窗口里做的事，和浏览器、命令行、Python 调用的是同一套能力。

桌面窗口

打包后的 Electron 窗口加载 Web UI：会话、工作区、审批、计划模式。本站主推这条路，不必先装 Node。

下载 Windows 桌面版

浏览器 Web

本机启动 Web UI，默认 http://127.0.0.1:3080。已有 Node 时可用 npx @deepseek-ai/dsh web。

命令行与自动化

headless 跑单次任务，ACP 给自动化客户端。适合脚本和流水线，不经过窗口。

Python SDK

把同一套循环嵌进自己的程序。从 文档枢纽 进 Python 指南。

插件扩展

工具、技能、子代理、沙箱、权限都是插件。不要改 agent-loop。以后资源库会收录验证过的 Skill、MCP 和插件，现在先看开发文档。
