桌面版下载

主推 Windows。其他系统与命令行写在本页下半，不替代安装包。

开发者预览。Windows 包未签名。装好后：设置 → 模型 → 填 DeepSeek API Key → 选择工作区，才能发消息。

Windows x64

NSIS 安装程序，默认装到 Program Files，需要管理员权限。约 390MB。

下载 .exe

macOS Apple Silicon

未签名 DMG。打开时若被拦截，到系统设置里允许这张盘。

下载 .dmg

Linux x64

AppImage。下载后 chmod +x 再运行。

下载 AppImage

没有安装包时

已有 Node 22.19 或 24、以及 pnpm：

  • npx @deepseek-ai/dsh web — 浏览器打开本地 Web UI
  • 源码：pnpm install、pnpm run build、pnpm dsh desktop
