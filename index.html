DeepSeek Harness

本地窗口 · 与 Web 同一套能力

读仓库、改文件、跑命令、走审批。

装完这三步就能发消息

01
安装桌面版，打开 DeepSeek Harness 窗口。
02
打开设置 → 模型，填入 DeepSeek API Key 并保存。不必重启。
03
选择工作区（你的项目目录）。选中之前输入框不可用。

它实际在干什么

对着仓库做事

读取和编辑工作区文件，运行命令，维护计划。权限策略要求时，会先问你。

用插件扩展

工具、技能、子代理、沙箱都是插件，不是改内核。同一套能力覆盖桌面、浏览器和命令行。

四种入口，桌面优先

桌面

无边框窗口加载同一套 Web UI。这是本站主推的用法。

Web / CLI / Python

npx @deepseek-ai/dsh web、headless 任务、Python SDK。说明在 产品 与 文档。
